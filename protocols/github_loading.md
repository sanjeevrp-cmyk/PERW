# GitHub Loading Protocol

Trigger PERW for paper ideation, literature/research gap, policy research, data feasibility, empirical design, causal inference, regression/robustness/mechanism, manuscript writing, journal selection, review or submission. Fetch CURRENT.md first; new projects use current stable; ongoing projects preserve locally adopted version when known. Then load core/PRINCIPLES.md, core/ROLE_ROUTING.md, core/WORKFLOW.md and only relevant stage/gate/protocol files. If GitHub cannot be accessed, state that and request the repo/file rather than pretending PERW was loaded.
