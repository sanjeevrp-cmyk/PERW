# Structural Escalation Protocol

If execution reveals a problem requiring change to Core Question, Claim Type, Evidence Architecture, key construct, primary evidence, geography, sample population, central claim, Paper Scope, or any causal design object, stop the affected branch and report: OBSERVED PROBLEM; EVIDENCE; AFFECTED GATE; AFFECTED DESIGN OBJECT; IMPLICATION; OPTIONS; WHICH OPTIONS CHANGE DESIGN; RECOMMENDATION; DESIGN DISCUSSION REQUIRED: YES. Do not silently redefine geography, construct, treatment, outcome, counterfactual, estimand, identifying assumption, or instrument.

Executor access failure alone is not a structural research-design escalation. Route it through `protocols/data_access_handoff.md`; escalate scientifically only if validation or true team-level unavailability threatens a frozen design object.
