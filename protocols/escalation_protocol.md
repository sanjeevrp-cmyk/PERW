# Structural Escalation Protocol

If execution reveals a problem requiring change to Core Question, treatment, estimand, main outcome, sample population, identifying assumption, causal claim, or Paper Scope, stop the affected branch and report: OBSERVED PROBLEM; EVIDENCE; AFFECTED GATE; AFFECTED DESIGN OBJECT; IMPLICATION; OPTIONS; WHICH OPTIONS CHANGE DESIGN; RECOMMENDATION; DESIGN DISCUSSION REQUIRED: YES. Do not silently redefine geography, treatment, outcome, counterfactual, or instrument.
