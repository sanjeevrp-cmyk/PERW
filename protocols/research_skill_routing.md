# Research Skill Routing Protocol

Use the host's native selection first. Select one or several appropriate skills in task order and load only relevant instructions. A directory router may locate specialist entries; use the authoritative active registry and actual task scope to establish what is installed and allowed. A local deterministic tool may request an explicit operation when executing a particular input payload. Ordinary multi-capability research continues as one task, with no general comparison requirement among suitable tools.

## Adoption and real use

Mature low-risk research, writing, exhibit and delivery modules can be integrated complete, with scripts, templates and necessary dependencies. Verify source, version, licensing, host compatibility, and applicable side effects before installing. Prefer officially supported installation paths; use the smallest useful check in its first real task and fix or restrict the affected function if it fails. Community use and upstream tests are relevant evidence of maturity. Search-only catalog entries need their own permission and practical fit before execution.

A new estimator, consequential measurement, data transfer or other claim-changing operation requires targeted validation or authority appropriate to that risk. Reuse applicable evidence. Classify admission as INSTALL, DISTILL, HOLD or REJECT in the existing registry or history. Record actual installed scope and version, verified operations, unresolved dependency/licensing restrictions, and retirement when an existing path has genuinely been replaced. Do not maintain duplicate active registers.

## Authority and evidence

PI decisions and the paper's applicable PERW, frozen design and execution authorization govern selected skills. Use bundled scripts within those limits. Tool defaults cannot silently change primary results, sample, claims, estimands, or causal design. Keep public search and external transfer subject to data permissions. Treat automated manuscript checks as checks of their specific job; preserve independent numeric verification and necessary scientific validation. No significance searches or suppression of unfavorable results.

Native discovery, actual task selection, software installation, particular executable operations and scientific validation describe different evidence. Report which skill and operation materially helped, and state limitations from actual use. Use a known implementation when no skill adds value. No equivalent review, benchmark contest or publication of a routing report is required solely because multiple tools are available.
