# Proposition / Rival-Discrimination Gate

**CONDITIONAL — viewpoint/theory-guided claims.** Test whether observable implications can distinguish the focal proposition from serious rival explanations.

Required checks: source viewpoint; mechanism; falsifiable proposition; predictions; rival propositions; observations that would support, weaken, or reject each account; data availability; and claim boundary.

Output: proposition–rival evidence matrix and GO / GO WITH REPAIR / HOLD / NO-GO. Evidence that can only confirm the focal proposition does not pass.
