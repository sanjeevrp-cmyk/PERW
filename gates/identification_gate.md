# Identification Gate

**MANDATORY FOR CAUSAL CLAIMS.** Required sequence: assignment → counterfactual → estimand → identifying assumption → estimator → inference → diagnostics → falsification. Also state the strongest rival causal explanation. Do not proceed merely because an estimator can technically be run.

Non-causal claims do not use this gate unless they rely on a causal identification argument; they remain subject to the universal and architecture-specific validity gates.
