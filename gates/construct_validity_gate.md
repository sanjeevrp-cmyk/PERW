# Construct Validity Gate

**CONDITIONAL — measurement and new-fact claims, and any project whose contribution depends on a new construct.**

Required checks: construct definition; content validity; observable inputs; coding and aggregation rules; provenance; measurement error; benchmark, convergent, discriminant, and predictive validity where appropriate; sensitivity to reasonable alternatives; coverage; missingness; and reproducibility.

Output: construct-validation plan, unresolved threats, evidence ceiling, and GO / GO WITH REPAIR / HOLD / NO-GO. A reproducible number is not necessarily a valid measure.
