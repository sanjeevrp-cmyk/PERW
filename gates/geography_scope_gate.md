# Geographic Scope / Spatial Validity Gate

**CONDITIONAL — regional/spatial claims or materially narrowed geographic samples.**

Required question: **WHY THIS GEOGRAPHY?**

A narrower geography passes only when it improves or enables identification, measurement, mechanism, institutional contrast, spatial interaction analysis, data quality, policy/scientific relevance, external validity learning, or another defensible contribution.

Changing only geography is not sufficient novelty. Audit boundary choice, spatial units, adjacency or distance construction, spillovers, dependence, support, representativeness, scale sensitivity, and generalization limits where relevant.

Output: scientific geography rationale, spatial-validity threats, residual contribution, and GO / GO WITH REPAIR / HOLD / NO-GO.
