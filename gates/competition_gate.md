# Competition Gate

**UNIVERSAL.** Search domestic and international published literature and recent working papers for the same question, mechanism, construct, empirical architecture, geography/institution, outcome, and policy/shock when relevant.

Output a closest-paper matrix, overlap by dimension, architecture comparison, residual contribution, and GO / GO WITH REPAIR / HOLD / NO-GO. High-level papers may benchmark scientific questions and architecture, but changing only geography, year, sample, or outcome is not sufficient novelty. “We did not find a paper” is a search result, not proof of nonexistence.
