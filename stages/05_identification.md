# 05 Evidence & Identification Blueprint

For every project map Core Question → Claim Type → Key Construct → Required Evidence → Rival Explanations → Evidence Architecture → Inference → Diagnostics → Falsification / Validation. For causal claims, assignment comes first and estimator second; state the counterfactual, estimand, identifying assumption, and strongest rival causal story.

For each consequential rival, describe how its observable implications differ from the intended interpretation and which approved comparison can distinguish them. If several explanations imply the same result, carry that ambiguity to the Claim Ladder. When adding controls also changes the sample, distinguish the support change from the conditioning comparison before interpreting attenuation.

Where causal ambition was declared, record its assignment-level feasibility assessment and explicit resolution under `protocols/research_genesis_branch_governance.md`. Ambition is not a causal claim; a material downgrade requires PI approval and existing scope/Gate reassessment where applicable. This adds no causal Gate for noncausal claims and relaxes no causal standard.
