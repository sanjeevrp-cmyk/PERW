# 06 Data & Measurement Engineering

Make construction reproducible. Audit provenance, units, identifiers, coverage, key constructs, measurement validity, sample funnel, missingness, and transformations. Support text measures, geographic/spatial data, networks, indices, and administrative/firm/city matching when relevant; audit treatment additionally for causal designs. Preserve authoritative links from data and code to machine-readable results for later publication exhibits. Before the first materially nontrivial claim-bearing formal estimation or inference, apply `protocols/method_runtime_readiness.md` where relevant, including temporal provenance and sample-composition diagnostics when support changes materially.

Before scaling unvalidated high-risk core constructions, apply `protocols/risk_based_measurement_validation.md`: stress-test actual unit/event/state, coding, relationship, and matching rules against source-backed typical and difficult cases; reuse valid early tests. Combine targeted independent review with necessary predeclared blind spot checks and common-error/omission discovery rather than mechanical full double coding. Material rule repairs require a dependency/status map and selective downstream revalidation/recomputation; unverified old results cannot support current claims. Existing measurement standards, scope freeze, and scientific authority remain unchanged.

## Three-class data-operation routing

Classify an operation by its scientific meaning and effect on approved objects, not by its name or reversibility. **Reversibility alone does not imply low risk.** Class 3 takes precedence when an operation also meets Class 2.

| Class | Operation | Existing route |
|---|---|---|
| **Class 1 — Approved routine transformations** | Already approved transformations that do not change scientific meaning. | Reuse existing implementations and proportionate checks; preserve raw inputs, units/IDs, merge diagnostics, missingness, sample accounting and provenance. Reuse decisions already settled by the approved task. |
| **Class 2 — High-risk measurement or scientific-object construction** | Event boundaries, historical states, entity relationships, complex matching, subjective coding or other unvalidated high-risk core construction. | Apply [risk-based measurement validation](../protocols/risk_based_measurement_validation.md) before scaling; retain necessary independent/blind review, common-error/omission checks and dependency-based revalidation. |
| **Class 3 — Frozen-object change** | An operation that changes a frozen sample, construct, primary evidence, central claim or another protected scientific object. | Stop only affected work and use [structural escalation](../protocols/escalation_protocol.md), [Genesis/Branch governance](../protocols/research_genesis_branch_governance.md) and existing Scope approval/Gate reassessment where required. Resume only under existing authority; unaffected approved work may continue. |

Use [skill routing](../protocols/research_skill_routing.md) within these boundaries. An external default or runnable example authorizes no automatic unmatched-record deletion, generic winsorization, automatic complete-case selection or default estimator selection. Follow the approved sample/construction/method rules; unresolved material decisions use existing governance. Guidance about merge cardinality does not prove that a selected function supports it. Do not modify approved Skill sources or source locks to bypass their validated limits. These classes clarify existing rules without changing Stage/Gate criteria, Scope freeze or scientific authority.
